# Chatzy

Phone-style messaging app for kids. Open index.html in a browser and use preview friend code LUNA-88.

The current build includes profiles, friend codes, direct messages, group chats, drawings, search, blocking, reporting, and safety guidance. Preview data is stored on the device.

The Supabase starter schema in supabase-schema.sql prepares the next phase: real accounts, friendships, conversation membership, real-time messages, and reports. Before public launch, the backend also needs complete row-level-security testing, server-side moderation, media scanning, retention/deletion controls, privacy disclosures, and legally required age/guardian consent.
